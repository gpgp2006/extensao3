

\chapter{OBJETIVO}
\label{capitulo-objetivo}
\section{Objetivo Geral}

Capacitar o público-alvo na implantação, configuração e administração de um servidor de alto desempenho para jogos eletrônicos na nuvem de forma gratuita e permanente, por meio da publicação de uma série prática de videoaulas focadas em conceitos de infraestrutura de redes, sistemas operacionais e segurança da informação.

\section{Objetivos Específicos}

\begin{itemize}
    \item Demonstrar o provisionamento e configuração de uma Máquina Virtual (VPS) na infraestrutura \textit{Always Free} da Oracle Cloud, utilizando a arquitetura ARM Ampere com sistema operacional Linux;
    \item Implementar o software de servidor PaperMC, aplicando otimizações de inicialização e rotinas de coleta de lixo (\textit{Aikar's flags}), além de configurar o suporte à compatibilidade multiplataforma com GeyserMC e Floodgate;
    \item Orientar a configuração de regras de controle de acesso à rede, tanto nas Listas de Segurança da Virtual Cloud Network (VCN) da Oracle quanto no \textit{firewall} local através do \textit{iptables};
    \item Apresentar o processo de aquisição e apontamento de domínios via Registro.br, delegando as zonas DNS para a Cloudflare e apresentando o DuckDNS como rota alternativa gratuita;
    \item Estabelecer políticas de proteção da infraestrutura, detalhando a criação de túneis seguros via Cloudflare Tunnel para administração remota por SSH e a elaboração de scripts automatizados de filtragem geográfica por prefixos de IP;
    \item Configurar um servidor web com Nginx para disponibilização pública de interfaces gráficas auxiliares, como mapas interativos via BlueMap, e orientar os procedimentos para indexação nos mecanismos de busca do Google.
\end{itemize}
